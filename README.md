# Kava Workers Resources

Shared resources for organizing kava bars. This repo goes with the Thicker Than Mud zine, but it is separate from the zine PDFs so the zine repo stays clean.

## What is here

- `contacts.md` — who to call, and what each one does.
- `guides/log-template.md` — a log template for writing down violations, with a date, time, who, and what happened.
- `guides/general-union-plan.md` — the one-page general union plan: the $500k wall, the anchor bar route, and the pattern contract outline, to take to EWOC.

## What will go here

- A short guide on how to file a wage complaint.
- A pattern contract checklist: the floor every bar in town can meet.
- Translations and local adaptations, when someone offers them.

## How to use this

Start with the zine, then use the log template. One line a day is enough. Patterns win cases.

If you are organizing at your bar, talk to an organizer first: EWOC, workerorganizing.org. Do not put personal information about workers or bars in this repo without their explicit say so.
